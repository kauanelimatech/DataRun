# DataRun

Dashboard privado para organizadores de eventos de corrida e caminhada, com indicadores de inscrições e divulgação no Instagram.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

As variáveis necessárias estão documentadas em `.env.example`. Não envie o arquivo `.env.local` ao repositório.
